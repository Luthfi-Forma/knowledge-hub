This is the first real post in `posts`, seeded to prove the content
collection schema works end to end: a valid frontmatter block passes
validation, and the page builds.

The site itself is a static Astro build — MDX files in, validated content
out. No backend, no database. Every new project — like
[Jabodetabek-Connect](/posts/jabodetabek-connect) — research note — like
[the Cikarang industrial-settlement study](/posts/cikarang-industrial-settlement-pattern)
— or photograph — like [an evening at Tanggamus](/posts/tanggamus-pier) —
starts as a file here.
