Atlas

Satu identitas untuk seluruh situs: Reading dan DATUM dilebur. Kertas krem dipertahankan, bahasa kartografis DATUM diangkat ke terang. Tidak ada toggle mode, tidak ada seam, tidak ada dua pohon DOM.

  1. 01Struktur menggantikan gambar. Hanya 4 dari 11 post punya cover; hierarki karena itu dibawa oleh ukuran plate, hatch, dan graticule — bukan foto.
  2. 02Legenda adalah navigasi. Setiap kode visual yang dipakai untuk menandai konten juga bisa diklik untuk memfilternya.
  3. 03Warna punya tugas, bukan selera. Satu warna = satu makna. Aksen berhenti jadi tekstur.
  4. 04Notasi jujur. Mono hanya untuk data yang benar-benar terukur: koordinat, jumlah, tanggal, satuan. Tidak untuk dekorasi.

01 · Warna

Sembilan token, satu tugas masing-masing

Nama token tetap sama seperti di global.css agar peleburan hanya mengganti nilai, bukan API — 72 rujukan var(--color-*) di modul scrollytelling ikut berubah tanpa satu edit React.

Perubahan terhadap hari ini bukan perbaikan kontras — palet lama sudah lulus AA (#38523A di kertas krem = 7,5:1; #6B6152 = 5,3:1) — melainkan pembagian peran: satu hijau yang mengerjakan enam tugas dipecah menjadi research / project / flag, dan ink-muted dinaikkan ke 8,3:1 karena kini memikul seluruh notasi mono 12px. Satu-satunya perbaikan aksesibilitas nyata di lapisan warna: line (1,5:1) berhenti dipakai sebagai batas kontrol, digantikan line-strong (3,2:1) yang memenuhi syarat komponen UI non-teks.

05 · Gerak & aksesibilitas

Aturan yang mengikat, bukan saran

Gerak

  • Hover/state: 120ms. Transisi tata letak: 200ms. Tidak ada di atas 300ms.
  • Nol animasi berulang; nol parallax dekoratif.
  • Jaring prefers-reduced-motion global dipertahankan — dan 4 modul scrollytelling wajib memanggil useReducedMotion() (celah nyata hari ini).
  • View transition CSS murni dipertahankan; seam & ModeController dihapus.

Diperbaiki dari audit

  • Batas kontrol interaktif 1,5:1 → 3,2:1 (syarat komponen UI non-teks).
  • Skip-link ke #main ditambahkan (kegagalan 2.4.1 hari ini).
  • aria-current="page" di nav utama, bukan hanya filter tipe.
  • Setiap chart Recharts wajib punya tabel data alternatif (kegagalan 1.1.1).
  • Pagefind di-restyle ke token ini — menutup utang teknis #1.
